# IDZ - Telegram-бот с отчетом Ozon

Итоговый проект по дисциплине.

## Что делает бот

1. Пользователь пишет боту `/start`.
2. Бот просит прислать Ozon Api-Key, потом Client-Id.
3. Ключи сохраняются в локальную базу данных (sqlite).
4. По команде `/report` бот идет в Ozon Seller API, забирает отчет по остаткам
   товаров на складах, строит столбчатый график и отправляет в чат картинку
   и csv-файл с данными.

Каждое действие пользователя (старт, ввод ключей, запрос отчета) пишется
в таблицу `actions` - простая история действий.

## Структура проекта

- `bot.py` - основной файл, логика диалога с пользователем
- `db.py` - работа с базой данных (таблицы clients и actions)
- `ozon_api.py` - запрос отчета по остаткам к Ozon API
- `report.py` - построение графика и сохранение csv
- `config.py` - загрузка токена бота из .env
- `data/` - сюда сохраняется база и сгенерированные отчеты (в git не попадают)

## База данных

Используется sqlite, файл `data/baza.db` создается автоматически при первом
запуске бота.

**Таблица clients** - хранит ключи пользователей (telegram_id, client_id, api_key)

**Таблица actions** - хранит историю действий (telegram_id, action, когда)

## Как запустить

1. Установить зависимости:
```
pip install -r requirements.txt
```

2. Создать файл `.env` на основе `.env.example` и вписать туда токен бота
   (получить токен можно у @BotFather в Телеграме):
```
BOT_TOKEN=твой_токен
```

3. Запустить бота:
```
python bot.py
```

## Важно

Это учебный проект, сделан максимально просто. Api-Key и Client-Id от Ozon
пользователь вводит сам в чате с ботом, в коде никакие реальные ключи не
хранятся.
